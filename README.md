# Chuyao Fu — Academic Website

Source for [chuyaofu.github.io](https://chuyaofu.github.io/), built with Jekyll and the [al-folio](https://github.com/alshedivat/al-folio) academic theme.

The site presents my research in world models, embodied AI, vision-language-action models, robot learning, and autonomous driving.

## Deployment

Pushes to `main` trigger `.github/workflows/deploy.yml`, which builds the site and deploys the generated output to the `gh-pages` branch.

## Local development

Use the Docker workflow described in [`INSTALL.md`](INSTALL.md), then open `http://localhost:8080`.
