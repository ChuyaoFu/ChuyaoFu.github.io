## Overview

This project asks how an embodied agent can evaluate imagined future rollouts when no
ground-truth reference video is available. It learns action-video compatibility as a
reference-free signal for assessing whether a generated rollout is consistent with the
conditioned robot action.

I lead this first-author project and am responsible for the problem formulation, method
design, experiments, and manuscript preparation. The work is currently in progress.
